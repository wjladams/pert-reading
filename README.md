# Daytona State — PERT Reading

**Goal:** Reach **Reading ≥106** (with Writing ≥103) for **ENC1101** at Daytona State.

Scores are **scaled** (50–150) and computer-adaptive. Only 25 of 30 questions count; the score is not a simple “X out of 30 correct.”

**Retake at DSC:** each section once per day; $10 student retest fee; scores valid 2 years.  
[DSC placement testing](https://www.daytonastate.edu/testing-center/placement-testing.html) · [DSC PERT libguide](https://library.daytonastate.edu/PERT)

---

## What Reading tests

From the official McCann / Florida study guide:

1. Main idea / summarize key ideas and events  
2. Support or challenge claims with evidence from the text  
3. Word / phrase meaning in context (including figurative language)  
4. Tone, word choice, and organizational structure  
5. Author’s purpose; how events relate  
6. Relationships within and between sentences  
7. Character traits / motivations (fiction and nonfiction)  
8. Compare two texts on similar topics  
9. Fact vs. opinion  
10. Evaluate reasoning / rhetoric in an argument  

**Test habits that help toward 106+**

- Untimed — slow down; reread the question before locking an answer (you **cannot** go back).  
- Read the **first and last sentence** of each paragraph for main idea.  
- For inference questions, eliminate choices that only **restate** the passage.  
- Prefer answers supported by the text over “sounds true in real life.”
