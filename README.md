# Daytona State — PERT Reading

**Start here → [Open the practice app](practice/)**  
Skill drills · mixed sets · mock exam · missed review · progress tracking

## Goal

Reach **Reading ≥106** (and Writing ≥103) for **ENC1101** at Daytona State.

Scores are scaled (50–150) and computer-adaptive — not a simple “X out of 30.” Untimed; you cannot go back after locking an answer.

## Get started (short path)

1. **Practice** in the [app](practice/) — start with **Drill** on weak skills, then **Mixed**, then a **Mock**.
2. Skim the official [PERT Student Study Guide (PDF)](PERT-StudentStudyGuide.pdf) Reading section + sample items.
3. When ready, retest **Reading** at DSC (walk-in Assessment Center; photo ID). Scores valid 2 years.
